ClassroomOps attendance workflow direct update

This overlay contains the date-based student attendance history, one-click
attendance disputes, admin attendance review sheet, scan-only live terminal,
upload-only roster/course/marks staging, responsive styles, tests, API changes,
and the attendance finalization migration.

Apply from either the parent directory or from inside the project:

  bash classroomops-attendance-workflow-update/APPLY_CLASSROOMOPS_ATTENDANCE_UPDATE.sh classroom-attendance-platform

If you are already inside classroom-attendance-platform, this also works:

  bash ../classroomops-attendance-workflow-update/APPLY_CLASSROOMOPS_ATTENDANCE_UPDATE.sh

The script detects the current project automatically when the optional target
argument is not valid.
